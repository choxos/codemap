codemap

Map any GitHub repository

codemap draws every source file of a public repository as one zoomable map. Folders become nested boxes sized by lines of code, and each file becomes a texture of its own code that sharpens into syntax colored text as you zoom in.

Try choxos/mlumr, expressjs/express, pallets/flask, BurntSushi/ripgrep, tidyverse/dplyr, or microsoft/vscode, which is too big to load whole and lets you pick a folder.

Files go straight from GitHub to your browser; nothing is uploaded or stored anywhere else.

GitHub token (optional)

Each map costs two GitHub API requests, and GitHub allows 60 an hour per network without a token. A fine-grained token with no extra permissions raises that to 5,000. It is saved in this browser's storage for this site, which other pages on the same github.io domain can read, and is sent only to api.github.com.
